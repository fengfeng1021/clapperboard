# 場記板 MVP

這是一個無框架的場記板 Web app，直接開啟 `index.html` 即可使用。

## 功能

- iPad 優先的完整場記板畫面
- 場記板板面採繁體中文欄位：片名、日期、場次、鏡號、次數、記憶卡、影格率、景別、收音、導演、攝影機、時碼
- 點擊場記板欄位即可修改主要資訊
- 資料頁：管理專案資料與完整場記欄位
- 紀錄頁：管理拍攝紀錄、狀態、場記備註與匯出
- 設定頁：選擇十種內建打板音效，並自定義場記欄位的輸入方式與選項
- 拍攝流程：打板、記錄並下一次、下一鏡、下一場、次數歸 1
- 本機保存：資料自動存在瀏覽器 `localStorage`
- 交接輸出：CSV、JSON、列印報表

## 使用方式

1. 開啟 `index.html`
2. 在場記板頁直接點擊欄位修改資訊
3. 拍攝時按「打板」
4. 拍完按「記錄並下一次」
5. 需要完整資料或輸出時切到「資料」或「紀錄」頁
